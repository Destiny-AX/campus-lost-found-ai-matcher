# 拾寻 Logo 设计方案与 AI 生成提示词

## 品牌背景

- 名称: 拾寻 (ShiXun)
- 含义: "拾" = 捡起/发现, "寻" = 寻找/追寻, 合起来是"找回遗失的美好"
- 品类: 城市失物招领 AI 平台
- 调性: 科技感 + 温暖 + 可信赖
- 主色: 蓝紫渐变 #0071e3 → #5e5ce6
- 现有标志: "拾"字图标 (圆角蓝方块内白色"拾"字)


## 方案一: 双字叠合 - 精炼徽章风 (推荐)

### 设计思路
"拾"与"寻"二字纵向叠合，共用左侧偏旁"扌"。两个字本质上是同一动作的两个方向 (捡到 vs 寻找)，共用字根象征"失与得的统一"。

### 画面描述
- 正方形构图，圆角处理
- 左侧共用"扌"偏旁，右上为"合"，右下为"寸"
- 蓝紫渐变填充，笔画有轻微书法粗细变化
- 底部小字: 城市拾遗网络

### 中文提示词 (复制发给 GPT)
```
一个极简的现代Logo设计，正方形构图1:1。

图标由汉字"拾"和"寻"纵向融合而成。两个字的左侧偏旁"扌"是共用的，右侧上半部分是"合"，下半部分是"寸"，两个字紧密相连形成一个整体徽章。字形的笔画有微妙的粗细变化，带有温和的毛笔书写感，但不失现代感。

图标采用蓝紫渐变填充（从左上#0071e3到右下#5e5ce6），背景为纯白色。

图标下方横排一行细体小字"城市拾遗网络"，深灰色。

整体风格: 极简、现代、有文化底蕴但不古板，适合科技产品Logo。矢量风格，字迹清晰可辨，无多余装饰。
```

### 英文提示词 (发给 Midjourney/DALL-E)
```
A minimalist modern logo, square 1:1 format, clean white background.

The logo fuses two Chinese characters "拾" and "寻" stacked vertically into one unified glyph. Both share the left radical "扌" (hand radical), the top-right is "合" and bottom-right is "寸", forming a single cohesive emblem.

Blue-to-purple gradient fill from top-left #0071e3 to bottom-right #5e5ce6. Strokes have subtle calligraphic thickness variation, modern yet elegant.

Below the icon: a thin line of small text "城市拾遗网络" in dark gray.

Vector style, simple, culturally rooted but contemporary. No extra decoration.
```


## 方案二: 抽象符号 - 六维匹配环

### 设计思路
取"拾"字抽象化: 偏旁"扌"变为三指手掌，"合"变为开口圆环(象征匹配完成)。外环用6段彩色弧线，对应产品六维匹配算法。

### 中文提示词
```
一个极简的现代App图标，正方形1:1，纯白背景。

核心图形: 一个由6段彩色弧线组成的开口圆环(不完全闭合)，颜色依次为蓝色、绿色、橙色、紫色、红色、黄色，象征多维度的精准匹配。

圆环内部是一只极简风格的手掌(3根手指)，深蓝色#0071e3，呈"捡起"姿势，手掌与圆环之间形成巧妙的负空间。

图标下方细体文字"拾寻"。

科技感、简洁、现代App图标质感。矢量扁平风格，无阴影。
```

### 英文提示词
```
A minimalist modern app icon, square 1:1, clean white background.

A broken circle of 6 colorful arcs (blue, green, orange, purple, red, yellow clockwise) symbolizing multi-dimensional matching. Inside the ring: a simplified hand silhouette with 3 fingers in a "picking up" gesture, deep blue #0071e3. Elegant negative space between hand and ring.

Below: thin text "拾寻" in dark gray.

Vector flat style, no shadows, modern tech aesthetic. Simple, bold, memorable.
```


## 方案三: 字标横排版

### 设计思路
保留现有"拾"字图标认知，升级字形 + 横排英文名 SHIXUN，适合网站导航栏和PPT。

### 中文提示词
```
一个现代科技品牌的横版Logo，纯白背景。

左侧: 圆角正方形，蓝色底(#0071e3)，内嵌白色简化"拾"字，笔画均匀流畅。

右侧横排: 大号无衬线字体"SHIXUN"，字母间距略宽，深灰色。字母"I"上方有一个微小发光蓝点，象征AI精准定位。下方小号中文"城市拾遗网络"，浅灰色。

图标与文字比例约1:4，左对齐。矢量极简风格，适合网站导航栏。
```

### 英文提示词
```
A modern tech brand horizontal logo, clean white background.

Left: rounded square icon, blue background #0071e3, white simplified Chinese character "拾" with clean even strokes.

Right: large uppercase sans-serif "SHIXUN" in dark gray, wide letter spacing, a tiny glowing blue dot above letter "I". Below: small Chinese text "城市拾遗网络" in light gray.

Icon-to-text ratio 1:4, left-aligned. Vector minimal style, suitable for website navbar.
```


## 推荐方案

| 方案 | 适用场景 | 推荐度 |
|------|---------|--------|
| 方案一 双字叠合 | Logo提交、海报、PPT封面 | 最推荐 |
| 方案二 六维环 | App图标、favicon | 推荐 |
| 方案三 字标横排 | 网站导航栏、PPT页脚 | 推荐 |

建议: 优先生成方案一作为主Logo，方案三作为横排版辅助Logo。
