# 拾寻 · 路演PPT大纲（10分钟版）

## 基本信息
- **总时长**：10分钟
- **页数**：12页
- **风格**：极简科技风，蓝绿色主色调，每页不超过3个要点

---

## 页面结构

### P1 封面（30秒）
- 大标题：拾寻 · 城市拾遗网络
- 副标题：AI 驱动的智能失物招领平台
- 团队信息 + 日期
- 背景：上海城市剪影 + 渐变

### P2 痛点引入（1分钟）
- 数据：上海日均遗失物品近万件
- 现状：微信群刷屏、朋友圈扩散、地铁站堆积
- 问题：信息碎片化、匹配靠运气、认领无保障

### P3 解决方案（1分钟）
- 一句话：拾寻用 AI + 信用体系重构失物招领流程
- 三个核心：
  1. 智能匹配（0-100% 匹配度）
  2. 信用体系（实名+评价+举报）
  3. 完整闭环（发布→匹配→认领→评价）

### P4 产品演示（2分钟）
- 截图/录屏展示：
  - 首页：记录列表 + 统计面板
  - 发布：表单 + AI 智能提取
  - 匹配：匹配度分数拆解
  - 认领：问答验证 + 审核流程

### P5 技术架构（1分钟）
- 前端：原生 JS/CSS，单页应用
- 后端：Vercel Serverless Functions
- 数据库：Supabase PostgreSQL
- AI：SiliconFlow API（文本+图片）
- 部署：零服务器运维成本

### P6 核心算法（1分钟）
- 多维度加权匹配：
  - 类别 25% + 颜色 20% + 地点 20% + 时间 15% + 文本 20%
- 图片语义相似度：向量余弦相似度
- 信用分计算：好评+10，差评-5，举报-20

### P7 数据与成果（1分钟）
- 24+ 示例记录，覆盖上海 10 个区
- 6 大功能模块完整闭环
- 36/36 自动化测试通过
- 技术栈全开源，零运维成本

### P8 竞品对比（1分钟）
| 维度 | 传统微信群 | 拾寻 |
|------|-----------|------|
| 信息组织 | 碎片化 | 结构化 |
| 匹配方式 | 人工浏览 | AI 智能匹配 |
| 身份验证 | 无 | 问答+审核 |
| 信用体系 | 无 | 完整评价机制 |
| 成本 | 人力维护 | 零运维 |

### P9 商业模式（30秒）
- 当前：免费公益平台
- 未来：
  - 企业版（高校/园区/地铁定制）
  - 保险合作（失物险）
  - 广告位（本地生活服务）

### P10 团队分工（30秒）
- 产品经理：需求分析、流程设计
- 前端开发：UI 实现、交互优化
- 后端开发：API 设计、数据库、AI 对接
- 测试运营：功能测试、用户反馈

### P11 未来规划（30秒）
- 微信小程序版
- 图片识别增强（多图匹配）
- 地图可视化（热力图）
- 区块链存证（认领记录上链）

### P12 结尾（30秒）
- Slogan：拾寻，让城市更有温度
- 二维码：shixun-lost-found.vercel.app
- 感谢语 + 联系方式
