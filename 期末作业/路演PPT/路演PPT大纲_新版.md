# 拾寻 · 路演PPT大纲（新版）

## 基本信息
- **总时长**：10分钟
- **页数**：12页
- **风格**：极简科技风，蓝紫渐变主色调，每页不超过3个要点

---

## 页面结构

### P1 封面（30秒）
- 大标题：拾寻 · 校园拾遗网络
- 副标题：AI 驱动的智能失物招领平台
- 团队信息 + 日期
- **背景**：北京城市剪影（央视大楼/中国传媒大学校门）+ 蓝紫渐变（#0071e3 → #5e5ce6）

### P2 痛点引入（1分钟）
- 数据：高校日均遗失物品数百件（校园卡、钥匙、耳机占比最高）
- 现状：微信群刷屏、朋友圈扩散、食堂/教学楼堆积
- 问题：信息碎片化、匹配靠运气、认领无保障

### P3 解决方案（1分钟）
- 一句话：拾寻用 AI + 信用体系重构失物招领流程
- 三个核心：
  1. 智能匹配（0-100% 环形进度条 + 6 维度条形图）
  2. 信用体系（实名+评价+举报）
  3. 完整闭环（发布→匹配→认领→评价）

### P4 产品演示（2分钟）
- **截图/录屏展示（新版界面）**：
  - 首页：全新卡片网格布局 + 搜索筛选组件 + 右侧 Inspector 信息面板
  - 发布：表单 + AI 智能提取（城市已改为北京市，支持朝阳区/传媒大学）
  - 匹配：匹配度环形进度条 + 彩色维度条形图（类别/颜色/地点/时间/文本/图片）
  - 认领：问答验证 + 审核流程
- **强调**：默认聚焦中国传媒大学，支持三间房街道级精准筛选

### P5 技术架构（1分钟）
- 前端：原生 JS/CSS，单页应用，响应式适配移动端
- 后端：Vercel Serverless Functions
- 数据库：Supabase PostgreSQL
- AI：SiliconFlow API（文本+图片）
- 部署：零服务器运维成本，已上线 https://shixun-lost-found.vercel.app

### P6 核心算法（1分钟）
- 多维度加权匹配：
  - 类别 25% + 颜色 20% + 地点 20% + 时间 15% + 文本 20%
- 图片语义相似度：向量余弦相似度
- 信用分计算：好评+10，差评-5，举报-20
- **新增**：乐观锁防并发、Rate Limiting 防刷、内存回退机制

### P7 数据与成果（1分钟）
- 24+ 示例记录，覆盖北京 16 区，聚焦朝阳区/传媒大学
- 6 大功能模块完整闭环
- 36/36 自动化测试通过
- 技术栈全开源，零运维成本
- **新增**：拾小寻 FAQ 智能助手、单用户演示模式、Inspector 信息面板

### P8 竞品对比（1分钟）
| 维度 | 传统微信群 | 拾寻 |
|------|-----------|------|
| 信息组织 | 碎片化 | 结构化 + 卡片网格 |
| 匹配方式 | 人工浏览 | AI 智能匹配 + 环形进度可视化 |
| 地域精度 | 无 | 市→区→街道→学校四级 |
| 身份验证 | 无 | 问答+审核 |
| 信用体系 | 无 | 完整评价机制 |
| 移动端 | 无 | 底部导航 + 触摸优化 |
| 成本 | 人力维护 | 零运维 |

### P9 商业模式（30秒）
- 当前：免费公益平台
- 未来：
  - 企业版（高校/园区/地铁定制）
  - 保险合作（失物险）
  - 广告位（本地生活服务）

### P10 团队分工（30秒）
- 产品经理：需求分析、流程设计
- 前端开发：UI 实现、交互优化、移动端适配
- 后端开发：API 设计、数据库、AI 对接、乐观锁/防刷机制
- 测试运营：功能测试、用户反馈

### P11 未来规划（30秒）
- 微信小程序版
- 图片识别增强（多图匹配）
- 地图可视化（热力图）

### P12 结尾（30秒）
- Slogan：拾寻，让城市更有温度
- 二维码：shixun-lost-found.vercel.app

## 设计建议（新版）

### 配色
- **主色**：#0071e3（蓝）→ #5e5ce6（紫）渐变
- **辅色**：#34c759（绿）
- **背景**：#ffffff（白）/ #f5f5f7（浅灰卡片背景）
- **文字**：#1d1d1f（深灰主文字）/ #6e6e73（次要文字）

### 字体
- 标题：思源黑体 Bold / Montserrat Bold
- 正文：思源黑体 Regular / Inter Regular

### 视觉元素
- **卡片样式**：圆角 16px、轻微阴影、悬浮上浮效果（参考新版界面）
- **进度条**：环形 SVG 进度条（匹配度展示）
- **标签云**：pill 形状标签（类别/颜色/地点筛选）
- **图标风格**：线性图标（SVG stroke），统一 1.5px 线宽
