## 录制建议

### 工具
- **录屏**：OBS Studio（免费）/ Camtasia / 剪映专业版
- **剪辑**：剪映（自动字幕）/ Premiere
- **配音**：直接口述，或剪映"文本朗读"功能

### 录制要点
1. **浏览器窗口**：固定 1920x1080，不要缩放
2. **鼠标轨迹**：放慢点击速度，让观众看清操作
3. **账号切换**：用两个浏览器（Chrome + Edge）分别登录不同账号，演示认领流程
4. **网络**：确保 Supabase 连接稳定，避免加载等待
5. **新版界面强调**：
   - 悬浮卡片时停顿 1 秒，展示上浮效果
   - 匹配页面重点展示环形进度条和彩色条形图
   - 点击拾小寻时展示 FAQ 展开动画

### 剪辑要点
1. **加速处理**：表单填写过程可 2x 加速
2. **字幕**：关键操作添加文字标注（如"点击这里""注意匹配度""看环形进度条"）
3. **BGM**：轻快科技风背景音乐，音量低于配音
4. **转场**：简单淡入淡出，不要花哨特效
5. **高亮**：用鼠标光圈或箭头标注关键 UI 元素
