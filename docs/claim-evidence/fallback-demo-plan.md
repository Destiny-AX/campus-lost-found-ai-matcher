# 面试现场降级演示方案

## 目标

模型服务异常时仍能完整讲清产品机制，同时不把规则结果包装成 AI 成功。

## 正常路径

使用 interview=1 参数打开发布页，展开 AI 处理信息。若 source 为 ai，展示实际模型、耗时和字段置信状态。

## 模型超时或限流

1. 保留页面返回的 heuristic_fallback。
2. 展开 AI 处理信息，展示 provider_timeout、provider_rate_limited 或其他标准化原因。
3. 强调总时间预算和最多一次模型降级。
4. 展示规则仍能提取物品、颜色、地点和模糊时间。
5. 手动确认待确认字段后继续七维匹配。

## 网络完全不可用

使用本地启动模式：

- npm start；
- 本地数据源为 demo_memory；
- 文本提取走启发式规则；
- 不宣称通知到达真实第二账号；
- 使用已保存的闭环证据截图和 claim-flow-evidence.json 讲解状态机。

## 禁止表述

- 不把 heuristic_fallback 称为模型识别成功。
- 不把 28 条离线结果称为线上准确率。
- 不把内存 PostgREST 合约测试称为生产 Supabase 实测。
- 不把单账号离线申请称为真实通知送达。
