# 90 秒面试演示脚本

## 0—15 秒：问题与输入

“拾寻解决的是失物信息不结构化、人工比对效率低和公开联系方式带来的隐私风险。我用一条自然语言描述启动演示。”

输入：昨晚在中国传媒大学图书馆丢了一个黑色 AirPods Pro，充电盒有一道划痕。

## 15—35 秒：AI 结构化与可观测性

展示自动填表与字段置信状态，再展开 AI 处理信息：

- 本次来源；
- 实际模型；
- 总耗时；
- 模型尝试；
- 是否降级及原因。

说明：模型结果只用于预填，失败时规则兜底，规则结果不计为模型成功。

## 35—55 秒：七维匹配

进入匹配页，展示类别、颜色、地点、时间、文本、图像和语义七个维度。

重点说明：

- 缺失维度会被剔除并动态重分权重；
- 展示证据覆盖和匹配理由；
- 排序分不是经过验证的准确率。

## 55—75 秒：隐私与认领

展示招领物品缩略图保持清晰，但游客联系方式、精确位置和认领答案不公开。说明双账号链路：

用户 B 申请认领 → 用户 A 收到通知并审核 → 审核通过后 B 才解锁联系方式 → 双方确认归还。

## 75—90 秒：Evaluation 与边界

展示 28 条离线标注集的 A/B/C 三组结果和消融。

收尾表述：

“这是小规模离线证据，不代表线上真实用户表现。下一步需要真实照片、双人复标和独立 Preview Supabase 验证，而不是继续堆功能。”
