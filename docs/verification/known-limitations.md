# 已知限制

- 本轮未提供真实 SiliconFlow Key，文本/视觉模型只完成代码兼容检查，未在线验证效果。
- Supabase Auth 邮箱密码流程已完成离线契约测试，但本轮未连接 Supabase；真实 Auth 邮件、Schema、RLS、Storage、并发和持久化仍需在 Preview/隔离环境验证。
- Supabase Auth 负责密码保存与校验；为兼容现有业务接口，登录成功后仍由应用签发 30 天 JWT，因此 Supabase 侧封禁或密码重置不能让已签发的应用 JWT 立即失效。生产化应增加会话版本或服务端撤销校验。
- 40 条记录是明确标注的演示种子数据，不代表真实用户或运营结果。
- Evaluation 页面展示的是指标定义与采集方案，HitRate@K、误匹配率、人工确认率均“待采集”。
- 实名、机构合作、通知外部触达是 Mock 或产品方案；微信登录已从当前用户入口移除。
- 启发式抽取覆盖常见中文表达，但不是通用 NLU；相对时间依赖 `Asia/Shanghai`，模糊时间要求人工确认。
- 7 维分数是候选排序原型，不是经标注集校准的准确率或概率。
- 图片本地特征适合演示颜色/哈希等信号，不能替代语义模型。
- 临时 ASCII 镜像首次 `npm install` 因 `skia-canvas` 下载 `ECONNRESET` 失败，原始失败输出保留；正式工作副本复跑成功（up to date）。
- 截图由 Edge 无头浏览器从实际本地页面生成；由于当前工具的 Windows 中文路径沙箱限制，未用内置图片查看器再次像素级人工审图，但已校验 7 张图片均非空且尺寸正确。
- 需要 Preview 环境才能验证 Vercel 路由、真实域名、在线 Key 和数据库的端到端行为。
