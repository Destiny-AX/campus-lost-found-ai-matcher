## 产品解读

- 基础元数据配置覆盖高，但在同色同类候选上触发较多阈值以上错误候选，离线误通知代理指标为 50.0%。
- 文本／语义配置在存在明确描述时排序较好，但对信息不足和无匹配查询更保守，无结果率为 25.0%。
- 七维融合在本数据集上取得最好排序，但这不等于模型准确率，更不能外推为线上找回率。

## 限制

- 28 条查询样本很小，没有置信区间或显著性检验。
- 候选与查询由同一轮设计，可能存在设计者偏差。
- 图像维度使用本地确定性特征夹具，不代表真实图片域表现。
- 标签尚未完成双人独立复标。
- 误匹配率是离线通知代理指标，不是用户投诉率。
