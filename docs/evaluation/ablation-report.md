## 解释

- 去掉图像后，正例排序没有变化，但低信息查询更容易低于结果地板分，结果覆盖率下降 10.7 个百分点。
- 去掉语义后，本小样本的 HitRate 与 MRR 没有可测变化，说明其他维度在当前样本中存在较强冗余；不能据此断言语义维度没有价值。
- 仅依赖类别和颜色时，Top-1 与 MRR 明显下降，并产生大量阈值以上困难负例，说明宽泛字段不适合直接触发通知。
- 图像使用确定性特征夹具，消融只能验证融合逻辑，不能作为在线视觉模型收益证明。

## 下一步验证

在用户提供真实拍摄照片后，应保持同一套标签，替换图像夹具并复跑评测；若样本扩展到真实照片，需要重新检查阈值与困难负例，而不是沿用本报告数字。
