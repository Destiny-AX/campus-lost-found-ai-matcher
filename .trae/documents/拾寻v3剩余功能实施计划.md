## Task 1: AI 结构化输入支持地点结构化提取

**Files:**
- Modify: `api/structured-input.js`

### 背景
当前 AI prompt 只要求提取 `location`（纯文本），但 v3 发布表单需要 `district`（区）、`street`（街道）、`detail_location`（具体位置）三个独立字段。需要让 AI 同时提取这三个字段，并在 heuristic fallback 中也做结构化解析。

### 步骤

- [ ] **Step 1: 修改 AI prompt，增加地点结构化字段**

在 `buildPrompt` 函数的 `### 5. location` 部分之后，增加：

```javascript
"### 5. location（纯文本，用于展示）",
"- 精确提取地点，保留关键地标",
"",
"### 5a. district（区/县）",
`- 必须是以下之一：${Object.keys(STREET_DATA).join("、")}`,
"- 从地点中识别所属区",
"",
"### 5b. street（街道/地标）",
"- 从地点中识别具体街道、商圈或地标名称",
"- 例如：南京东路、人民广场、徐家汇",
"",
"### 5c. detail_location（具体位置，选填）",
"- 更精确的位置描述，如'地铁站5号口'、'图书馆三楼'",
```

同时修改输出示例，增加 `district`、`street`、`detail_location` 字段。

- [ ] **Step 2: 修改 normalizeStructured，解析结构化地点**

在 `normalizeStructured` 函数中，从 AI 返回的数据中提取：

```javascript
// 地点结构化
const district = pickEnum(data.district, Object.keys(STREET_DATA), "");
const street = String(data.street || "").slice(0, 40);
const detailLocation = String(data.detail_location || "").slice(0, 60);
```

并返回到结果对象中。

- [ ] **Step 3: 修改 heuristicExtract，增加地点结构化解析**

在 `heuristicExtract` 函数中，地点提取逻辑之后，增加：

```javascript
// 结构化地点解析
let district = "";
let street = "";
let detailLocation = "";

// 从 location 中匹配区
const districtMatch = location.match(/(黄浦区|静安区|徐汇区|长宁区|普陀区|虹口区|杨浦区|浦东新区|闵行区|宝山区|嘉定区|金山区|松江区|青浦区|奉贤区|崇明区)/);
if (districtMatch) {
  district = districtMatch[1];
  // 从 location 中匹配街道（从该区对应的街道列表中找）
  const possibleStreets = STREET_DATA[district] || [];
  for (const s of possibleStreets) {
    if (location.includes(s)) {
      street = s;
      break;
    }
  }
}
// detail_location：location 去除区和街道后的剩余部分
detailLocation = location.replace(district, "").replace(street, "").replace(/^[\s·-]+/, "").slice(0, 60);
```

并在返回对象中增加 `district`、`street`、`detail_location`。

**注意**：`STREET_DATA` 需要在前端可访问，但 `structured-input.js` 是后端文件。后端需要自行定义 `STREET_DATA` 常量，或从前端传入。这里选择在后端重新定义一份 `STREET_DATA`（与前端保持一致）。

## Task 2: 前端表单自动填充级联选择器

**Files:**
- Modify: `script.js`

### 背景
AI 提取返回 `district` 和 `street` 后，前端 `fillFormFields` 函数需要自动选择发布表单中的 districtSelect 和 streetSelect，而不是只填充 location input。

### 步骤

- [ ] **Step 1: 修改 fillFormFields，增加级联选择器填充**

在 `fillFormFields` 函数中，在 `locationInput` 处理之后，增加：

```javascript
// 结构化地点自动填充级联选择器
const districtSelect = form.querySelector('select[name="district"]');
const streetSelect = form.querySelector('select[name="street"]');
const detailInput = form.querySelector('input[name="detail_location"]');

if (districtSelect && s.district) {
  setSelectValue(districtSelect, s.district);
  // 触发级联更新街道选项
  const event = new Event("change");
  districtSelect.dispatchEvent(event);
}

if (streetSelect && s.street) {
  // 由于 district change 是异步更新 street options，需要延迟设置
  setTimeout(() => {
    setSelectValue(streetSelect, s.street);
  }, 50);
}

if (detailInput && s.detail_location) {
  detailInput.value = s.detail_location;
}
```
