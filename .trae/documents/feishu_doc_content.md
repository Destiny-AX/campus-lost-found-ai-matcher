# 拾寻 v2 — 城市拾遗网络

基于 AI 的智能失物招领平台，让城市中每一件遗失物品都有机会回到主人手中。

## 核心功能

### 智能发布
支持失物和招领两种信息发布。用户可上传物品照片，系统自动调用 AI 视觉模型（Qwen3-VL-8B）识别物品类别、颜色、品牌、特征等语义信息，生成结构化描述。同时支持自然语言输入，AI 自动提取为结构化字段（类别、颜色、地点、时间等），降低发布门槛。

### AI 匹配
采用 7 维加权匹配算法，综合计算失物与招领信息的相似度：
- 类别（13%）：支持关联类别匹配（如"证件"与"学习用品"）
- 颜色（8%）：基于 RGB 色彩空间距离计算相似度
- 地点（14%）：城市级地点邻接图，支持相邻区域匹配
- 时间（11%）：按时间差梯度评分（0.5h 内满分，24h 以上低分）
- 文本（14%）：Jaccard 词汇交集 + Dice 双字组系数混合
- 图像（20%）：颜色直方图余弦相似度 + 感知哈希汉明距离 + 主色距离
- 语义（20%）：AI 识别的物品名称、特征、品牌等深层语义匹配

匹配结果附带可读的匹配原因说明，帮助用户快速判断。

### 隐私保护
三层模糊化机制，未实名认证用户只能查看脱敏信息：
- 位置模糊化：精确地址 → "XX路附近"或"XX区范围内"
- 时间模糊化：精确时间 → "今天下午""3天前上午"等模糊时段
- 描述模糊化：完整描述 → 保留前 30 字 + "实名认证后查看完整描述"
- 联系方式：未认证时隐藏，显示"查看联系方式"按钮

物品所有者和已实名认证用户可查看完整信息。

### 实名认证
Mock 实名认证流程：用户输入真实姓名（≥2字）和身份证末 4 位数字，系统校验通过后标记为已认证。认证后解锁完整信息查看权限，信用积分从 5 提升至 10。认证信息仅存储 SHA-256 哈希摘要，不保留明文。

### 消息通知
站内短轮询通知机制（8 秒间隔）。当 AI 匹配成功时自动推送通知，用户可在通知中心查看并标记已读。导航栏红点徽标实时提示未读数量。

### 代保管体系
物品可寄存至代保管点（便利店、智能快递柜、物业中心等），系统自动生成 6 位防混淆取件码（剔除 0/O/1/I/L 等易混淆字符）。同时对接认证机构（地铁失物招领中心、派出所、机场失物招领处、市民服务中心），机构保管物品直接显示联系方式。

## 使用流程

1. **发布信息**：登录后选择"丢失"或"捡到"，填写物品信息或上传照片，AI 自动补全结构化字段
2. **AI 匹配**：系统自动在失物与招领信息之间进行 7 维匹配，按相似度排序展示
3. **实名认证**：完成实名认证后解锁联系方式和完整描述等敏感信息
4. **联系取回**：查看联系方式联系对方，或通过代保管点取件码取回物品

## 技术架构

### 前端
- 原生 HTML/CSS/JavaScript 单页应用（SPA）
- 三断点响应式布局（桌面/平板/手机）
- Canvas 图像特征提取（颜色直方图 + 感知哈希）
- Dialog 元素弹窗交互

### 后端
- Vercel Serverless Functions（Node.js）
- RESTful API：records、auth、notify、custody、analyze-image、structured-input
- 自建 HS256 JWT 认证（中文 payload UTF-8 编解码）

### 数据层
- Supabase PostgreSQL 主存储
- 内存 Map 双层兜底（Supabase 不可用时自动降级）
- localStorage 前端 Token 持久化

### AI 能力
- 图像语义识别：SiliconFlow + Qwen3-VL-8B-Instruct
- 自然语言结构化提取：SiliconFlow + Qwen3-8B
- 本地启发式 fallback（API 不可用时自动降级）

### 部署
- Vercel 平台一键部署
- 环境变量管理敏感配置（Supabase Key、SiliconFlow API Key、JWT Secret）
